# 砂錆の地 RUSTWASTE 操作マニュアル

対象：Phase 7（仕上げ版）　※フェーズごとに更新します

## 1. このゲームについて

砂と錆に覆われた荒野で生き延びる、オープンワールドのサバイバルRPGです。主人公もメインストーリーも勝利条件もありません。目標は自分で決めます。序盤は無力で、負けたり捕まったりしながら這い上がっていくこと自体が楽しさになるよう設計しています。

現在の版（Phase 7）では、町での売買・交易・仲間の雇用、派閥との関係、賞金首の換金、戦闘、装備、けがと治療、空腹、能力の成長、地図、セーブとロードができます。さらに、自分の拠点を建てて、採掘・加工・農業・研究を仲間に任せられます。拠点が育つと盗賊などが攻めてきます。地域ごとの天気（砂嵐・酸性雨・灰降り）、道を行き来する隊商や巡回部隊、廃墟に残された遺物の探索、効果音も加わりました。

## 2. はじめ方

1. 公開URLをAndroid Chromeで開きます
2. タイトル画面右上の「ビルド番号」と日時で、最新版かどうかを確認できます
3. 初回は「はじめから」、2回目以降は「つづきから」を押します

| ボタン | 内容 |
|---|---|
| つづきから | 自動セーブから再開します（日数・時刻・仲間の名前が表示されます） |
| はじめから | 新しい一団で始めます。最初に**拠点への襲撃の頻度**（なし・少なめ・普通・多め）を選びます。仲間の顔ぶれは毎回変わります |
| ロード／読み込み | セーブスロットや、書き出したテキストから再開します |

### ホーム画面に追加する

Chromeのメニュー（右上の︙）→「ホーム画面に追加」で、アプリのように全画面で起動できます。横向きにすると「縦にしてください」と表示されます。

## 3. 画面の見方

| 場所 | 内容 |
|---|---|
| 左上 | 日数・朝昼夕夜・天気（晴れ以外は黄色）、時刻、所持金（錆貨） |
| ミニマップの下 | 襲撃の予告（あと何時間か）と、襲撃中の赤い帯 |
| 右上 | 時間の速さ（停止／0.5／1x／2x／3x）、その下にミニマップ（タップで全体地図）と、いる町の名前 |
| 下段 | 仲間の顔アイコン（横にスクロールできます） |
| 最下段 | 範囲・全員・追従・待機・休む（戦闘中は「退却」）・☰（メニュー） |

選択中の仲間は、足元に**緑のリング**が出ます。

### 頭上の名札

人物の頭の上に、名前や役割が表示されます。店の建物の上には店の種類の看板が出ます。

| 色 | 意味 |
|---|---|
| 緑 | 仲間（名前） |
| 黄色 | 店主・酒場の主人・役人・隊商の商人（話しかけると売買などができる） |
| 水色 | 雇える人（雇い代つき） |
| 赤 | 敵（襲ってくる相手・敵対している派閥） |
| 白っぽい色 | 衛兵・護衛などそのほかの人 |

賞金首には「賞金○○」、倒れた人には「（気絶）」などが付きます。「設定」→「頭上の名札」で、役割のある人だけ（標準）・全員・なしを切り替えられます。屋根のある建物の中にいる人の名札は、外からは表示されません。移動先には回転する小さな印が出ます。

顔アイコンの下の緑の線は体力の目安です。その下に「出血」「気絶」「死亡」「治療」「休息」などの状態が赤字で出ます。出血中は顔の枠が赤く光ります。

## 4. 仲間の操作

| 操作 | 動き |
|---|---|
| 顔アイコンをタップ | その仲間を選択 |
| 選択中の顔アイコンをもう一度タップ | カメラをその仲間へ移動（さらにタップで詳細画面） |
| 画面の仲間をタップ | その仲間を選択（見た目より広めに反応します） |
| 地面をタップ | 選択中の仲間がそこへ走ります |
| 長押し | その場所・人物に対してできる行動の一覧を表示 |
| 「全員」 | 仲間全員を選択 |
| 「範囲」 | 押してから指でなぞると、囲んだ仲間を選択（終わると通常に戻ります） |
| 「待機」 | 選択中の仲間を止めます |
| 「休む」 | 選択中の仲間がその場に座り、けがの回復が3倍になります。移動を指示すると立ち上がります |
| 「追従」 | 選択中の仲間をカメラが追いかけます。ドラッグで解除 |

- 複数人を選んで地面をタップすると、少しずつ間隔を空けて集まります
- 崖や廃墟の柱は自動で避けて回り込みます。遠い場所を指定すると、進める所まで進みながら道を探し直します。どうしても行けないときはログに「そこへは行けない」と出ます
- 近くに複数の人物がいる場所をタップすると、だれを選ぶか一覧が出ます
- 流れ者（仲間以外の人）をタップすると淡い色のリングが付き、長押しで「話す」「攻撃する」などの行動を選べます

## 5. 町と派閥

### 派閥

| 派閥 | 特徴 |
|---|---|
| 塩路商会 | 塩と鉄の取引で荒野をつなぐ商人の連合。砂町・塩の市・鉄床の3つの町 |
| 白灯の教団 | 規律に厳しい宗教国家。祈りの泉と、城壁に囲まれた白灯の都。町に入るときに通行料を取る。錆骨を忌み嫌う |
| 砂鼠団 | 盗賊団。北東の「砂鼠の巣」に頭目がいる。最初から敵 |
| 灰喰らい | 東の灰の高地に住む人食いの集団。誰にでも襲いかかる。最初から敵 |

メニューの「派閥」で、それぞれの評判（-100〜100）と状態（友好・中立・敵対・指名手配中）を確認できます。

| 評判が上がる | 評判が下がる |
|---|---|
| 店で取引する（少しずつ） | その派閥の人を攻撃する・殺す |
| 賞金首を引き渡す | 店で盗みに失敗する |
| その派閥の人を手当てする | 通行料を断る |

評判が -40 を下回ると、その派閥の人々から敵とみなされます。評判が高いと店の値段が少し安くなります。

### 町での行動

- 町の人をタップすると話しかけます。仲間がそばにいないときは、選択中の仲間がその人の所へ歩いて行き、**着いたら自動で会話が始まります**（1回押すだけ）。話しかけた相手はその場で立ち止まって待ちます
- **会話中は時間が止まります**。会話や店の画面を閉じると、元の速さに戻ります
- 店主・酒場の主人・役人は**建物の中**にいます

### 建物の中に入る

- 町の店と家は、正面の入口から中に入れます。中の地面をタップすると歩いて入ります
- 選択中の仲間が中にいるとき、またはカメラの中心を建物の中に合わせたときは、**屋根が消えて中が見えます**
- 中には店のカウンターや棚、酒場のテーブル、警備所の牢、家の寝床などがあります
- 拠点の小屋も同じように、中に入ると屋根が消えます。酸性雨のときは建物の中へ避難しましょう
- 見張り塔・野営地のテント・灰喰らいの小屋には入れません
- **店主**：「店を見る」で売買。**酒場の主人**：食べ物・仲間探し・噂話。**警備所の役人**：賞金首の引き渡し・罰金の支払い
- 町の住人や衛兵とも会話できます。役に立つ話が聞けることもあります

### 店と交易

店では「買う」「売る」「盗む」を選べます。取引する仲間は、店のそばにいる仲間から選べます（買った物はその仲間の持ち物に入ります）。

- 町ごとに値段が違います。特に**塩・鉄板・布・薬草**などの交易品は差が大きく、安い町で買って高い町で売るともうかります（噂話や町の説明がヒントになります）
- 在庫は毎日入れ替わります。売った物は店に並びます
- 武器屋は武器と素材、防具屋は防具・素材・義肢、酒場は食料しか買い取りません

### 仲間を雇う

酒場の客に話しかけると、雇い代を払って仲間にできます（無料でついてくる人もいます）。一団は最大10人です。

### 賞金首

砂鼠団の頭目などには賞金がかかっています。気絶させて**縛り**、**担いで**警備所の役人のそば（8m以内）まで運び、役人に話しかけると賞金を受け取れます（生け捕りのみ）。縛った町の住人を送り届けると、礼金がもらえます。

### 指名手配と牢

町の中や衛兵の前でその派閥の人を襲う、店で盗みに失敗する、などをすると**指名手配**されます。

- 手配中は、その派閥の衛兵と役人が襲ってきます
- 手配は3日たつと自然に解けます。警備所で**罰金**を払っても解けます
- 衛兵に倒されると**牢へ連行**され、2日間は縛られたまま動けません。期間が終わると釈放され、手配も解けます。仲間が牢へ行って縄をほどけば脱獄もできます（衛兵には見つからないように）

### 通行料（白灯の教団の町）

教団の町に入ると衛兵に止められ、通行料を求められます。

| 選択 | 結果 |
|---|---|
| 払う | その日は自由に出入りできる |
| 断る | 評判が下がり、その日はその町の衛兵が襲ってくる |
| 引き返す | 何も起こらず、町の外へ下がる |

一団に**錆骨**がいる場合、教団の町の中では衛兵に襲われます。連れて行くときは注意してください。

### 忍び歩きと盗み

仲間を長押し →「忍び歩き」で、腰を落としてゆっくり歩きます。盗賊に見つかりにくくなり（隠密が高いほど効果が大きい）、店で盗むときの成功率も上がります。盗みの成功率は、窃盗の能力と、店の近くにいる衛兵の数で決まります。

## 6. 地図

右上のミニマップをタップすると全体地図が開きます。

- 「全体」「広域」「近く」で縮尺を切り替えます
- 地図の上をタップすると、その地点へ選択中の仲間を移動させられます。下の一覧の「ここへ」で見つけた町へ向かうこともできます
- 町は近づくと地図に名前が載ります（それまでは「？」）
- 緑の点が仲間、赤い点が襲ってきている敵です
- ▲は見つけた廃墟（黄色＝まだ調べていない、灰色＝調べた）、◆は近くを通る隊商（黄色）や巡回部隊（派閥の色）です
- 遠い場所へは、道を通って進みます

## 7. 拠点づくり

町の外の好きな場所に拠点を作れます。最初の建物を置いた場所が拠点の中心になり、中心から90mが拠点の範囲です。

### 建てる（照準方式）

1. メニュー（☰）→「拠点」→「建設」で建てたい物の「建てる」を押す
2. 画面の中央に照準（丸）と、半透明の下書きが出ます。画面をドラッグして照準を建てたい場所に合わせます（緑＝置ける、赤＝置けない。理由も表示されます）
3. 「回転」で向きを変え、「確定」で建設予定地を置きます。続けて同じ物を置けます。終わったら「やめる」

**石壁**は、照準を始点に合わせて「始点」→ 画面を動かして照準を終点に合わせて「終点」で、一直線に引けます（斜めも可）。続けて「終点」を押すと、前の終点から壁をつなげられます。

建物は地面の高い側に合わせて建ち、低い側は土台で埋まります。地面の傾きが大きすぎる場所、岩や崖、町の中、道の上には建てられません。

### 材料

材料は、拠点の**倉庫**と、拠点の中にいる仲間の持ち物から使われます。

| 材料 | 手に入れ方 |
|---|---|
| 石材 | 石切り場（灰色の大きな岩）で掘る、雑貨屋で買う |
| 鉄鉱石 | 鉄の鉱脈（赤茶色の大きな岩）で掘る |
| 鉄板 | 町で買う、精錬炉で鉄鉱石3つから作る |
| 布 | 町で買う（祈りの泉が安い） |

### 建物

| 建物 | 働き |
|---|---|
| 倉庫 | 採掘した物・作った物がここに入る。採掘の仕事には倉庫が必要 |
| 寝床 | 「休む」を指示すると空いている寝床で眠り、回復が5倍 |
| 小屋 | 簡単な住まい。中に寝床などの家具を置ける（通り抜けできる） |
| 石壁・門 | 壁は通れない。門はタップで開け閉め（閉めると敵も味方も通れない） |
| 井戸 | 30m以内の畑の育ちが倍になる |
| 畑 | 穀物を育てる（種まき→1日で実る→収穫） |
| 調理台 | 穀物2つから平焼きパン |
| 研究台 | 研究を進める |
| 精錬炉 | 鉄鉱石3つから鉄板（研究「精錬」） |
| 風車発電機 | 電力+10（研究「風力発電」） |
| 採掘機 | 鉱脈の上に建てると電力で自動で掘る（電力-5） |
| 武器作業台・防具作業台 | 予約した武器・防具を作る |
| 防衛塔 | 25m以内の敵に自動で矢を放つ |
| 檻 | 縛った人を担いで運び、檻をタップ→「檻に入れる」 |

建物をタップすると、その建物でできること（門の開け閉め、倉庫を見る、取り壊すなど）が出ます。建設中の建物は、進み具合と足りない材料が出ます。

### 仕事

「拠点」→「仕事」で、仲間ごとに仕事の優先度を決めます（1が最優先、押すたびに 1→2→3→なし）。拠点の中にいて、移動の指示も戦闘もしていない仲間は、自動で仕事をします。

| 仕事 | 内容 | 伸びる能力 |
|---|---|---|
| 建築 | 建設予定地を建てる | 労働 |
| 採掘 | 近くの石切り場・鉱脈で掘って倉庫へ運ぶ | 労働・筋力 |
| 農業 | 畑の種まきと収穫 | 農業 |
| 調理 | 調理台で平焼きパンを作る | 料理 |
| 加工 | 精錬炉で鉄板、作業台で武器・防具を作る | 鍛冶 |
| 研究 | 研究台で研究を進める | 研究 |

拠点にいる仲間は、空腹になると倉庫の食料を自分で取って食べます。

### 研究と生産

- 「拠点」→「研究」で研究する項目を選びます。研究台と「研究」の仕事をする仲間が必要です。電力があると2倍の速さです
- 「拠点」→「生産」で、武器作業台・防具作業台で作る物を予約します。鍛冶が高いほど品質の良い物ができます（研究「上質な鍛冶」でさらに上がりやすくなります）
- 「拠点」→「倉庫」で中身を確認し、選択中の仲間に取り出したり、持ち物をしまったりできます
- 一部の研究には**遺物**（古代の部品・古い記録板・動力核）が必要です。廃墟の箱で見つけた遺物を倉庫にしまってから研究を始めてください（始めるときに倉庫から使います）
- 研究「義肢づくり」「上等な義肢」で、防具作業台で義肢を作れるようになります

### 拠点への襲撃

- 拠点の建物（完成したもの）が5つ以上になると、ときどき拠点が襲われます。頻度は「はじめから」のときに選び、あとから「設定」で変えられます（「なし」にすると起きません）
- 襲撃のおよそ4時間前（ゲーム内）に**予告**が出ます。画面上部に「襲撃の予告：〜 あと約○時間」と表示され、振動と音でも知らせます。仲間を拠点に集め、武器を持たせて備えましょう
- 襲ってくるのは、砂鼠団の襲撃隊・灰喰らいの群れ・白灯の討伐隊（教団から敵とみなされているときだけ）です。人数は拠点の規模で増えます
- 襲撃隊は拠点へ向かってきます。**石壁や門に行く手をはばまれると、壊しにかかります**（壊された建物の材料は戻りません）。防衛塔は近づいた敵に矢を放ちます
- 守り手が拠点にいなくなる（全員倒れる・逃げる）と、襲撃隊は倉庫の物と所持金の一部を奪って去ります。半分以上を倒すと退いていきます
- 倒れた襲撃者は縛って檻に入れたり、賞金首なら引き渡したりできます

## 8. 世界の出来事

### 天気

地域ごとに起きやすい天気があります。天気は一団のいる地域で決まり、地域を出ると次第に晴れていきます。

| 天気 | 起きる地域 | 影響 |
|---|---|---|
| 砂嵐 | 砂の平原 | 見通しが悪くなる。盗賊もこちらに気づきにくくなる |
| 酸性雨 | 錆の荒地 | 屋根の下にいない人の頭・胸・腕が少しずつ傷む（一定以下にはならない）。外套と頭の装備で軽くなり、錆骨はより傷みやすい。拠点の小屋の中や町の中なら平気 |
| 灰降り | 灰の高地 | 見通しが悪くなる |

### 隊商と巡回部隊

- 町と町を結ぶ道を、塩路商会の**隊商**（商人・荷運び・護衛）と、各派閥の**巡回部隊**が行き来しています。アプリを開いている間は、見えていない所でも進み続けます
- 隊商の商人に話しかけると、その場で売り買いできます（値段は行き先の町に近い）
- 護衛や巡回兵は、近くに現れた盗賊などの敵と戦います。こちらが指名手配されていると襲ってきます

### 廃墟の探索

- 荒野に点在する廃墟には、古い**箱**が残されています。近づくと地図に▲で載ります
- 箱をタップまたは長押しして「調べる」を選ぶと、選択中の仲間が調べに行き、しばらくしゃがんで中身を探します
- 遺物（研究の素材。高く売れる）、鉄くず、応急処置キット、ときには武器・防具・義肢が見つかります。1つの箱は1回だけ調べられます

### 効果音

攻撃が当たる・受け止める・かわす・矢を放つ・壁が壊れる・買い物・建物の完成・襲撃の警報などで音が鳴ります。砂嵐では風の音、酸性雨では雨の音がします。最初に画面に触れたときから鳴り始めます。「設定」で、あり・なしと音量（小・中・大）を変えられます。

## 9. 戦闘

### 盗賊団

荒野には盗賊の一団「砂鼠団」がうろついています。ゲーム内で2時間ほどたつと現れはじめ、一団を見つけると襲ってきます。襲ってくる敵の足元には**赤いリング**が出ます。

| 種類 | 特徴 |
|---|---|
| 飢えた盗賊 | 弱い。粗末な棍棒や錆びた刀を持つ |
| 砂鼠団の手下 | そこそこ強い。弓を持つ者もいる |
| 砂鼠団の頭目 | 強い。良い武器と防具を持ち、賞金がかかっている |

一団が全員倒れると、盗賊は**食料と所持金の3割を奪って去っていきます**。命までは取りません（ただし出血を放っておくと死にます）。設定の「盗賊の出現」で、新しく現れないようにもできます。

### 戦い方

戦闘は自動で進みます。プレイヤーが出すのは大まかな指示だけです。

| 操作 | 内容 |
|---|---|
| 敵をタップ | 選択中の仲間がその敵を攻撃します |
| 何もしない | 攻撃された仲間は自動で反撃し、近くで仲間を襲っている敵にも向かっていきます |
| 「退却」ボタン | 戦闘中は「休む」が「退却」に変わります。選択中の仲間が敵から離れる方向へ走ります |
| 地面をタップ | 移動の指示は戦闘より優先されます（攻撃されると反撃します） |

攻撃が当たるか、受け止められるか、かわされるかは能力で決まります。

| 能力 | 戦闘での効果 | 伸ばし方 |
|---|---|---|
| 近接攻撃 | 威力と攻撃の速さ、相手に受け止められにくくなる | 剣・鈍器・長柄・素手で戦う |
| 射撃 | 弓の威力と速さ | 弓で撃つ |
| 防御 | 攻撃を受け止める確率（正面からの近接攻撃のみ） | 受け止める |
| 回避 | 攻撃をかわす確率 | かわす |
| 筋力 | 鈍器の威力。武器の必要筋力に足りないと攻撃が遅くなる | 鈍器で戦う・重い荷物 |
| 耐久 | 受けるダメージが減る | ダメージを受ける |

負けて、倒れて、起き上がるたびに強くなっていくのがこのゲームの遊び方です。

### 武器の種類

| 種類 | 特徴 |
|---|---|
| 刀剣 | 切れ味で出血させる。扱いやすい |
| 鈍器 | 重い一撃。防具の上からでも効き、筋力で威力が上がる。出血は少ない |
| 長柄 | 間合いが長く、先に当てられる |
| 弓 | 20mほど離れた所から撃てる。受け止められない（矢は消費しません） |
| 素手 | 武器がないとき。弱い |

武器や防具には品質（粗悪・普通・上質・逸品）があり、品質が高いほど威力・防御力が上がります。

## 10. 装備

詳細画面の「装備」で、武器・頭・胴・上着・脚・靴・背中の7か所を確認できます。

- 持ち物の武器・防具は「装備」で身に着けます（同じ場所の物は持ち物へ戻ります）
- 装備は「外す」で持ち物へ戻せます
- 防具は覆っている部位に当たったときだけ効きます（例：兜は頭、脛当ては脚）
- 背負い袋を背負うと持てる重さが増えます
- 身に着けた物は、見た目にも反映されます

## 11. 倒した相手をどうするか

倒れた（気絶・死亡）相手や縛った相手を長押しすると、次の行動を選べます。先に行動させる仲間を選択しておいてください。

| 行動 | 内容 |
|---|---|
| 持ち物をあさる | 相手の装備・持ち物・所持金を取れます。取った物は選択中の仲間に入ります |
| 縛る | 気絶している相手を縛ります。目を覚ましても動けず、戦えません |
| 縄をほどく | 縛った相手を解放します |
| 担ぐ | 倒れた相手（敵でも仲間でも）を肩に担いで運びます。担いでいる間は遅く、戦えません |
| とどめを刺す | 倒れた相手を攻撃します |
| 治療する | 敵でも治療できます |

担いでいる仲間を長押しすると「降ろす」を選べます。倒れた仲間を担いで退却すれば、敵から逃がせます。

頭目には賞金がかかっています。縛って町の警備所へ連れて行くと賞金に換えられます（「5. 町と派閥」参照）。

## 12. 体とけが

### 部位ごとの体力

体は「頭・胸・腹・左腕・右腕・左脚・右脚」の7つの部位に分かれ、それぞれに体力があります。詳細画面の「体」では、人体の図が部位ごとに色分けされます。

| 色 | 状態 |
|---|---|
| 緑 | ほぼ無傷 |
| 黄 | 傷を負っている |
| 橙 | 重傷 |
| 赤 | 体力が0以下（その部位が使えない） |
| 灰（点線） | 失った |
| 灰（実線） | 義肢 |

- **頭・胸・腹**のどれかが0以下になるか、血液が50を下回ると**気絶**します。気絶中は倒れたまま動けません。体力と血液が戻ると目を覚まします
- **頭・胸・腹**のどれかが最大値のマイナス分まで下がると**死亡**します
- **脚**が片方使えないと脚をかばってゆっくり歩き、両方使えないと**這って**移動します
- **腕**が両方使えないと治療ができません
- 手足は大きなダメージで**失う**ことがあります。義肢を「持ち物」から付けると、また使えるようになります（等級が高いほど丈夫で速い）

### 出血と血液

切り傷は出血します。出血は時間とともに自然に弱まりますが、放っておくと血液が減り、気絶や死亡につながります。人体の図では出血している部位に赤い滴が付きます。

### 治療

| 方法 | 内容 |
|---|---|
| 自動の止血 | 出血している仲間がいると、手の空いている仲間が自動で駆け寄り、止血だけ行います |
| 治療する | 長押しの一覧や詳細画面の「治療する」で、選択中の仲間が手当てします。だれも選択していなければ本人が自分で手当てします。悪い部位から順に処置し、体力も回復させます |
| 休む | 出血が止まった部位は時間とともに回復します。座って休むと回復が3倍になります |

治療には**包帯**か**応急処置キット**を使います（治療役か患者の持ち物から使われます）。応急処置で戻せるのは最大体力の8割までで、残りは休んで回復させます。気絶している人も治療できます。仲間以外の人も治療できます。

### 空腹

空腹度は時間とともに減ります。手持ちの食料があれば、空腹になる前に自動で食べます。食料が尽きると能力が下がり（空腹-10%、飢餓-30%）、さらに放っておくと腹にダメージを受けて命に関わります。

## 13. 種族

| 種族 | 特徴 |
|---|---|
| 砂人 | 荒野に最も多い人々。得意も不得意もなく、何でも覚える |
| 角人 | 額に角を持つ大柄な種族。力と頑丈さに優れるが、よく食べ、身のこなしは重い |
| 錆骨 | 機械の体で動く種族。食事をしないが自然にはほとんど治らず、**修理キット**でしか治療できない |

## 14. 能力の成長

能力は「使うと上がる」仕組みです。レベルが高いほど上がりにくくなります。

| 能力 | このフェーズでの伸ばし方 | 効果 |
|---|---|---|
| 筋力 | 重い荷物を持って歩く | 持てる重さが増える |
| 敏捷 | 走る | 走る速さが少し上がる |
| 耐久 | ダメージを受ける・気絶する | 受けるダメージが減り、各部位の最大体力が増える |
| 医療 | 治療する | 手当てが速く、回復量が多くなる |

戦闘の能力は「8. 戦闘」、隠密と窃盗は「5. 町と派閥」、労働・料理・農業・鍛冶・研究は「7. 拠点づくり」を参照してください。

## 15. 持ち物

詳細画面の「持ち物」で、仲間ごとの持ち物と重さを確認できます。持てる重さを超えると動きが遅くなります。

- **装備**：武器・防具を身に着けます
- **食べる**：食料をその場で食べます
- **渡す**：ほかの仲間に1つ渡します（包帯を治療役にまとめる、など）
- **付ける**：義肢を、失った手足に取り付けます

## 18. 時間

ゲーム内の1日は、1x のとき現実の約20分です。右上のボタンで速さを変えられ、「停止」中も仲間への指示は出せます（再開すると動き出します）。

アプリを閉じている間は時間は進みません。アプリを切り替えたり画面を消したりすると、自動で一時停止して自動セーブし、描画も止まります。戻ったときは一時停止のままなので、状況を確かめてから速度ボタンで再開してください。

## 20. メニューのその他のタブ

- **一団**：仲間の一覧と所持金。「詳細」で体・装備・持ち物・能力、「見る」でカメラがその仲間へ移動します
- **ログ**：これまでの出来事。画面下に一瞬出る通知もここで後から確認できます
- **設定**：下の表のとおり

| 設定 | 内容 |
|---|---|
| 画質：自動 | 初回に端末の性能を数秒計測し、低・中・高から自動で選びます |
| 画質：低 | 影なし・描画距離128m・解像度1.0倍。古い端末向け |
| 画質：中 | 影あり・描画距離192m・解像度1.25倍。標準 |
| 画質：高 | 高精細な影・描画距離256m・解像度1.5倍 |
| 明るさ | 暗め・標準・明るめ・最大。画面全体の明るさを変えます |
| 夜の明るさ | 暗い・普通・明るい。夜が暗くて見えにくいときは「明るい」にしてください |
| 頭上の名札 | 役割のある人（標準）・全員・なし |
| 解像度の自動調整 | 重くなると描画解像度を下げ、余裕が戻ると元に戻します |
| 省電力（30fps） | 描画を1秒30回に抑えて、電池の減りと発熱を少なくします |
| デバッグ表示 | fps・描画時間・描画命令数・三角形数・画質を左上に表示 |
| 振動 | 長押しや選択時の短い振動のオン・オフ |
| 効果音 | 効果音のあり・なしと、音量（小・中・大） |
| 拠点への襲撃 | なし・少なめ・普通・多め（拠点の建物が5つ以上で起きます） |
| 時間を60倍で早送り | 昼夜の移り変わりを確認する検証用の機能 |
| 盗賊の出現 | 「なし」にすると新しい盗賊が現れなくなります（今いる盗賊は残ります） |

## 21. 不具合の報告方法
