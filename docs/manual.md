# 砂錆の地 RUSTWASTE 操作マニュアル

対象：Phase 1（操作と移動の検証版）　※フェーズごとに更新します

## 1. このゲームについて

砂と錆に覆われた荒野で生き延びる、オープンワールドのサバイバルRPGです。主人公もメインストーリーも勝利条件もありません。目標は自分で決めます。序盤は無力で、負けたり捕まったりしながら這い上がっていくこと自体が楽しさになるよう設計しています。

現在の版（Phase 1）では、3人の一団を選んで荒野を歩かせること、時間の操作、セーブとロードができます。戦闘・会話・建築などは次のフェーズ以降で追加されます。

## 2. はじめ方

1. 公開URLをAndroid Chromeで開きます
2. タイトル画面右上の「ビルド番号」と日時で、最新版かどうかを確認できます
3. 初回は「はじめから」、2回目以降は「つづきから」を押します

| ボタン | 内容 |
|---|---|
| つづきから | 自動セーブから再開します（日数・時刻・仲間の名前が表示されます） |
| はじめから | 新しい一団で始めます。仲間の顔ぶれは毎回変わります |
| ロード／読み込み | セーブスロットや、書き出したテキストから再開します |

### ホーム画面に追加する

Chromeのメニュー（右上の︙）→「ホーム画面に追加」で、アプリのように全画面で起動できます。横向きにすると「縦にしてください」と表示されます。

## 3. 画面の見方

| 場所 | 内容 |
|---|---|
| 左上 | 日数・朝昼夕夜、時刻、所持金（錆貨） |
| 右上 | 時間の速さ（停止／0.5／1x／2x／3x） |
| 下段 | 仲間の顔アイコン（横にスクロールできます） |
| 最下段 | 範囲選択・全員・追従・その場で待機・メニュー |

選択中の仲間は、足元に**緑のリング**が出ます。移動先には回転する小さな印が出ます。

## 4. 仲間の操作

| 操作 | 動き |
|---|---|
| 顔アイコンをタップ | その仲間を選択 |
| 選択中の顔アイコンをもう一度タップ | カメラをその仲間へ移動 |
| 画面の仲間をタップ | その仲間を選択（見た目より広めに反応します） |
| 地面をタップ | 選択中の仲間がそこへ走ります |
| 長押し | その場所・人物に対してできる行動の一覧を表示 |
| 「全員」 | 仲間全員を選択 |
| 「範囲選択」 | 押してから指でなぞると、囲んだ仲間を選択（終わると通常に戻ります） |
| 「その場で待機」 | 選択中の仲間を止めます |
| 「追従」 | 選択中の仲間をカメラが追いかけます。ドラッグで解除 |

- 複数人を選んで地面をタップすると、少しずつ間隔を空けて集まります
- 崖や廃墟の柱は自動で避けて回り込みます。遠い場所を指定すると、進める所まで進みながら道を探し直します。どうしても行けないときはログに「そこへは行けない」と出ます
- 近くに複数の人物がいる場所をタップすると、だれを選ぶか一覧が出ます
- 流れ者（仲間以外の人）をタップすると淡い色のリングが付き、長押しで行動を選べます。「話す」「攻撃する」などは今後のフェーズで使えるようになります

## 5. カメラの操作

| 操作 | 動き |
|---|---|
| 1本指でドラッグ | カメラを移動（指を離すと少し滑ります） |
| 2本指でつまむ・広げる | ズームアウト・ズームイン |
| 2本指でひねる | 水平方向に回転 |
| 2本指で上下になぞる | 見下ろす角度を調整（一定範囲内） |

## 6. 時間

ゲーム内の1日は、1x のとき現実の約20分です。右上のボタンで速さを変えられ、「停止」中も仲間への指示は出せます（再開すると動き出します）。

アプリを閉じている間は時間は進みません。アプリを切り替えたり画面を消したりすると、自動で一時停止して自動セーブし、描画も止まります。戻ったときは一時停止のままなので、状況を確かめてから速度ボタンで再開してください。

## 7. セーブとロード（メニュー →「セーブ」）

| 項目 | 内容 |
|---|---|
| 自動セーブ | アプリを切り替えたときと、60秒ごとに自動で保存されます |
| スロット1〜3 | 「保存」で手動保存。「読込」で再開、「消去」で削除 |
| 書き出す | 進行状況を文字列にします。コピーしてメモ帳などに保存しておくと、別の端末や再インストール後でも続きから遊べます |
| 読み込む | 書き出した文字列（W3D で始まります）を貼り付けて再開します |

ゲームを更新しても古いセーブはそのまま読み込めます。

## 8. メニューのその他のタブ

- **一団**：仲間の一覧と所持金。「見る」でカメラがその仲間へ移動します
- **ログ**：これまでの出来事。画面下に一瞬出る通知もここで後から確認できます
- **設定**：下の表のとおり

| 設定 | 内容 |
|---|---|
| 画質：自動 | 初回に端末の性能を数秒計測し、低・中・高から自動で選びます |
| 画質：低 | 影なし・描画距離128m・解像度1.0倍。古い端末向け |
| 画質：中 | 影あり・描画距離192m・解像度1.25倍。標準 |
| 画質：高 | 高精細な影・描画距離256m・解像度1.5倍 |
| 解像度の自動調整 | 重くなると描画解像度を下げ、余裕が戻ると元に戻します |
| デバッグ表示 | fps・描画時間・描画命令数・三角形数・画質を左上に表示 |
| 振動 | 長押しや選択時の短い振動のオン・オフ |
| 時間を60倍で早送り | 昼夜の移り変わりを確認する検証用の機能 |

## 9. 不具合の報告方法

エラーが起きると、画面上部に赤枠の「エラーが発生しました」パネルが出ます。「コピー」を押して、その内容をそのまま貼り付けて送ってください。ビルド番号と端末情報も自動で含まれます。
