# 砂錆の地 RUSTWASTE 操作マニュアル

対象：Phase 0（描画基盤の検証版）　※フェーズごとに更新します

## 1. このゲームについて

砂と錆に覆われた荒野で生き延びる、オープンワールドのサバイバルRPGです。主人公もメインストーリーも勝利条件もありません。目標は自分で決めます。序盤は無力で、負けたり捕まったりしながら這い上がっていくこと自体が楽しさになるよう設計しています。

現在の版（Phase 0）は、スマホで3D表示が快適に動くかを確かめるための検証版です。人物の操作・戦闘・建築などは次のフェーズ以降で追加されます。

## 2. はじめ方

1. 公開URLをAndroid Chromeで開きます
2. タイトル画面右上の「ビルド番号」と日時で、最新版かどうかを確認できます
3. 「はじめる」を押すとゲームが始まり、可能な端末では全画面になります

### ホーム画面に追加する

Chromeのメニュー（右上の︙）→「ホーム画面に追加」で、アプリのように全画面で起動できます。

### 縦画面で遊びます

横向きにすると「縦にしてください」と表示されます。

## 3. 画面の見方

| 場所 | 内容 |
|---|---|
| 左上 | 日数・朝昼夕夜・時刻 |
| 右上 | 時間の速さ（停止／0.5／1x／2x／3x） |
| 左（緑の文字） | デバッグ表示（fps・描画負荷など） |
| 左下 | 追従、早送り×60 |
| 右下 | 設定 |

## 4. カメラの操作

| 操作 | 動き |
|---|---|
| 1本指でドラッグ | カメラを移動（指を離すと少し滑ります） |
| 2本指でつまむ・広げる | ズームアウト・ズームイン |
| 2本指でひねる | 水平方向に回転 |
| 2本指で上下になぞる | 見下ろす角度を調整（一定範囲内） |

- **追従**：近くの人物をカメラが追いかけます。1本指でドラッグすると解除されます
- **早送り×60**：時間を60倍で進めます。昼夜の移り変わりを確認する検証用の機能です

## 5. 時間

ゲーム内の1日は、1x のとき現実の約20分です。アプリを閉じている間は時間は進みません。いつ中断しても損をしない作りです。

アプリを切り替えたり画面を消したりすると、自動で一時停止し描画も止まります（自動セーブは Phase 1 で追加します）。

## 6. 設定（右下「設定」）

### 画質

| 設定 | 内容 |
|---|---|
| 自動 | 初回起動時に端末の性能を数秒計測し、低・中・高から自動で選びます |
| 低 | 影なし・描画距離128m・解像度1.0倍。古い端末向け |
| 中 | 影あり・描画距離192m・解像度1.25倍。標準 |
| 高 | 高精細な影・描画距離256m・解像度1.5倍 |

### 表示

- **解像度の自動調整**：動きが重くなると描画解像度を自動で下げ、余裕が戻ると元に戻します。画面が少しぼやけるときはこれが働いています
- **デバッグ表示**：fps（1秒あたりの描画回数）、ms（1回の描画時間）、call（描画命令の数）、tri（三角形の数）、現在の画質と解像度を表示します

### その他

- **振動**：被ダメージや襲撃開始時の振動（Phase 3 以降で使用）のオン・オフ
- **全画面**：全画面表示に切り替えます

## 7. 不具合の報告方法

エラーが起きると、画面上部に赤枠の「エラーが発生しました」パネルが出ます。「コピー」を押して、その内容をそのまま貼り付けて送ってください。ビルド番号と端末情報も自動で含まれます。

動作が重い場合は、デバッグ表示の fps と画質をあわせてお知らせください。
